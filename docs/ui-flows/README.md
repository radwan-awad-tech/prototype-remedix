# MediStaff HR Frontend UI & User-Flow Documentation Pack

This documentation pack provides a comprehensive overview of the MediStaff HR application's frontend organization, navigation structure, and major user journeys.

## Documentation Files

1.  **[Navigation Map](./navigation-map.md)**: Outlines the sidebar structure, sub-menus, and footer actions.
2.  **[Page Grouping by Module](./page-grouping.md)**: Details the pages and key components within each functional module.
3.  **[Key User Journeys](./user-journeys.md)**: Describes common user workflows and interactions.
4.  **[Key UI Interactions](./interactions.md)**: Explains the major UI patterns (DataTable, Drawers, Modals, Wizards) used across the system.
5.  **[RBAC Mapping](./rbac-mapping.md)**: Details the role-based access permissions for each major path.
6.  **[Flows & Dependencies](./flows-and-dependencies.md)**: Documents major create/edit/review flows, important panels, and page-level dependencies.

## Purpose

This documentation is intended for:
- **Designers**: To understand the current UI patterns and navigation logic.
- **Frontend Developers**: To quickly navigate the codebase and understand how pages and components are grouped.
- **Backend Developers**: To identify the API requirements for each frontend flow and user action.
- **Product Managers**: To review the implemented user journeys and identify potential gaps or improvements.

## Current UI Reality

All documentation is grounded in the current frontend implementation. It reflects the existing pages, navigation items, and UI components. Mock behaviors are noted where applicable, and no fictional workflows have been invented.
